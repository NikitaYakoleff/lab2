# Лабораторная работа 2. Pandas: Series, DataFrame и основные операции

Скрипт `lab2_pandas.py` проходит по всем шести задачам из конспекта на одной
таблице сотрудников (12 человек, пять отделов). Данные записаны прямо в коде,
скачивать ничего не нужно.

## Задачи

1. Создание Series и DataFrame: ряд с произвольным индексом, таблица из словаря,
   первые и последние строки, типы столбцов, `describe`.
2. Индексация и фильтрация: `loc` по отделу, `iloc` по номерам, фильтр по
   зарплате, новая колонка `total_comp`, удаление `hire_date`.
3. Пропуски: подсчёт по столбцам, заполнение зарплаты средним по отделу,
   заполнение бонуса нулём, удаление строк, где зарплаты так и нет.
4. Группировка: средняя зарплата по отделам, `agg` с тремя метриками,
   `pivot_table`, сортировка по убыванию.
5. Объединение: `merge` с таблицей руководителей, добавление строки через
   `concat`, сброс индекса.
6. Мини-анализ: топ-3 по компенсации, средние зарплата и бонус в одной таблице,
   доля сотрудников с зарплатой выше 75000.

## Запуск

```
pip install -r requirements.txt
python lab2_pandas.py
```
